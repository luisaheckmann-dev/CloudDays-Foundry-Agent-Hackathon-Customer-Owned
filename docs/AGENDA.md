# 210-Minute Learning Agenda

[Home](../README.md) | [Setup](CUSTOMER-SETUP.md) | [Labs](LABS.md)

**Audience:** Browser users new to agents. No programming or local
development environment required. Use one customer identity per person,
preferably one customer project per person; explicitly approved team
projects share a data boundary. No password sharing.

## Separate Prework: Not Inside the 210 Minutes

Allow **60-90 minutes or more** for technical setup and rehearsal **after**
customer approval, plus organizational lead time for subscription access,
admin authorization/consent, billing, provider registration, quota,
network/private endpoints, and identity policy. These can take days and
are not guaranteed to finish in the suggested technical estimate.

The customer follows [setup sections 1-7](CUSTOMER-SETUP.md) from zero:
approve the environment, create the dedicated RG and Foundry resource/project,
verify human/runtime identity access, deploy an eligible model, address
monitoring, and verify browser file transfer. A customer admin performs
privileged steps when participants lack authority. The instructor does not
precreate or lend infrastructure.

Participants create the baseline, grounded agent and store in Labs 1-2
using setup sections 8-10. An independent authorized learner can simply
follow setup and labs sequentially without an event.

## Learning Outcomes

Create your own prompt agents, attach your own four-file knowledge store,
verify real citations, resolve current/withdrawn policy conflicts, distinguish
static inventory from live access, reject unsupported actions/commitments,
and measure agent behavior with a consistent manual rubric.

## Completion

Your customer owns every operational artifact. Record actual completed
setup, baseline E01/E03/E05, all ten improved fixed tests, core scoring,
source readback, observed limitations and cleanup responsibility.
The [acceptance criteria](EVALUATION.md#acceptance) apply. A written analysis,
pasted document context, or another person's demo cannot replace your own
customer cloud/retrieval evidence.
